An implementation of Conway's Game of Life in C using OpenGL/GLFW for graphics

Implementation:
The simulation uses an active cell system to check only cells that are alive, or have recently changed.

Controls:
Space to pause/resume
wasd to move cursor
enter to change state of the currently selected cell
r to reset the board

Status:
This is a side project that I am currently working on. I am using it to learn OpenGL, shaders, and graphics.
